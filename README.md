# Privacy Requirements Analyzer

Bachelor Thesis Project

Automatic detection of privacy requirements from software documentation and legal alignment with user rights.

## Features

- Privacy Requirement Detection
- GDPR Article Mapping
- CCPA Rights Mapping
- Explainable Predictions
- Web-based Interface

## Technologies used

- Python
- Flask
- BERT
- Sentence-BERT
- Scikit-learn
- NLP
