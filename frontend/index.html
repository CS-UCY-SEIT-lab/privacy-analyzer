About this platform

✕

This platform was developed at the University of Cyprus as part of a thesis project. It focuses on the automatic detection of privacy requirements from software documentation and their mapping to relevant user rights.

The system supports both manual input and file-based input (e.g. csv, xlsx). It operates in two main stages. First, it identifies which requirements are privacy-related. Then, it maps the detected requirements to corresponding user rights using a hybrid analysis approach.

The goal of this tool is to assist developers, researchers and practitioners in understanding how software requirements relate to privacy concepts, improving transparency and supporting compliance-aware development.

Additionally, users are encouraged to review the results of Stage 1 carefully. If any requirements are incorrectly classified as privacy-related or non-privacy-related, they can be adjusted before proceeding. This helps improve the overall accuracy of the analysis and ensures more reliable mapping in the next stage.

If you have any questions or would like further information, feel free to contact us.
